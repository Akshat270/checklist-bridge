# Video prompt: Checklist Bridge promo

Create a **45-second vertical video (1080×1920)** promoting **Checklist Bridge**, a free, open-source VS Code extension for developers who use Claude Code. Also export 1:1 for the LinkedIn feed.

**What it does:** when Claude Code needs you to do something by hand (create an API key, run a command, test a page), the steps get buried in the chat. Checklist Bridge puts them in a checklist next to the chat. You tick tasks, add a note or screenshot, and press Share. Claude only sees what you've shared.

**Tagline:** "Give every Claude Code chat its own checklist."

**Style:** calm and polished, like Linear. Dark VS Code look (`#1f1f1f` background, `#e6e6e6` text), indigo accent `#5e63e6`, green for done, red for urgent. Split screen: Claude chat on the left, narrow checklist panel on the right. Smooth zooms, tasks sliding in, checkboxes ticking. Light lo-fi music, soft tick sounds. Big bold captions on every scene (most people watch muted). No Anthropic logo.

## Scenes
1. **(0–3s)** A developer scrolls up an endless chat. Caption: **"Wait… what did Claude ask me to do?"**
2. **(3–8s)** Steps pop out of the chat and scatter: "Create a Stripe API key", "Add it to .env", "Test checkout". Caption: **"Manual steps get lost in the chat."**
3. **(8–14s)** A checklist panel slides in beside the chat. Tasks appear as Claude types. Caption: **"Checklist Bridge: every chat gets its own checklist."**
4. **(14–21s)** The next task is pinned on top with a command and a **Copy** button. An urgent task turns red. Caption: **"The next task is always on top."**
5. **(21–29s)** Tick a task, type a note, paste a screenshot, press **Share**. It moves to "Shared with Claude". Caption: **"Claude only sees what you share."**
6. **(29–36s)** A "Decide" section asks "Which payment gateway?" with options and Claude's pick. Claude keeps coding on the left. Caption: **"Decide later. Claude keeps working."**
7. **(36–45s)** End card: name, tagline, badges "Free", "Open source", "macOS · Windows · Linux", and "Search **Checklist Bridge** in VS Code". Small footer: "Not affiliated with Anthropic."

**Don't invent features.** Everything stays on the user's computer, setup is automatic, and it works in VS Code, Cursor and VSCodium. Use the real screenshots in the repo's `docs/` folder as reference images.
