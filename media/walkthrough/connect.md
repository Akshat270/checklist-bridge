## Connect Claude Code

Checklist Bridge connects itself to Claude Code when VS Code starts. There's nothing to type.

If this step isn't ticked yet:

- **Claude Code isn't installed.** Install it, then click **Connect Claude Code**.
- **It's installed somewhere unusual.** Set `checklistBridge.claudePath` to the full path of the `claude` command, then click **Connect Claude Code**.

Works with Claude Code in the terminal and in the VS Code extension.
